One line of horror, written by a small pure-stdlib Python program. It self-checks the kit's gates (single sentence, 1–200 characters, UTF-8, one line) and writes the line to `/output/entry.txt`:

> Last night the baby monitor played a lullaby in my voice, from the nursery where my daughter sleeps alone.

The scare is earned, not announced: nothing in the line says "scary". The horror is the implication — something in the nursery has learned the parent's voice, and the child sleeps alone.

## Run it

```sh
python3 main.py
```
